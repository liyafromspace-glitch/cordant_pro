# Cordant prototype build plan

1. Establish reusable tokens for typography, color, spacing, borders, elevation and motion.
2. Build shared shell components: navigation, status badges, cards, progress rail, evidence drawers and buttons.
3. Implement the incident workspace with authority lineage, control diff, evidence claims and time reconstruction.
4. Add blast radius, remediation compilation, two-person approval, external execution and independent verification.
5. Add a portfolio view using the same exception, evidence-freshness and severity primitives.
6. Verify keyboard input, reduced-motion behavior, responsive layout and every primary transition.

The prototype is a dependency-free web app so it can be opened locally or hosted as static files.
